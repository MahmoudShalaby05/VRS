# DriveRed — Vehicle Rental System (VRS)

[![Repository](https://img.shields.io/badge/GitHub-VRS-blue)](https://github.com/MahmoudShalaby05/VRS)

**DriveRed** is a full-stack vehicle rental web application. Customers browse and book cars online; administrators manage the fleet, reservations, users, and damage reports through a dashboard. The backend uses **Spring Boot** with **JPA** and **MySQL**; the frontend is **HTML, CSS, and JavaScript** served by the same application.

> **Repository:** [https://github.com/MahmoudShalaby05/VRS](https://github.com/MahmoudShalaby05/VRS)

## Project overview

DriveRed (VRS) simulates a modern car rental platform:

| User type | Capabilities |
|-----------|----------------|
| **Customer** | Register, log in, search vehicles, view details, complete checkout with rental plans (daily / weekly / monthly / yearly), manage profile, submit post-rental damage reports |
| **Administrator** | Manage vehicles, bookings, users, and damage reports via the admin dashboard |

**Architecture:** layered **REST API** — browser calls `/api/*` endpoints; **controllers** delegate to **services** (business rules); **repositories** persist **JPA entities** to **MySQL** (`vrs_db`).

```
Browser (static pages)  →  Controllers  →  Services  →  Repositories  →  MySQL
```

## Features

- User registration and authentication (profile, password, photo)
- Vehicle catalog with filters and comparison on the vehicles page
- Car details and checkout with **server-side pricing**
- Rental bookings linked to users and vehicles; availability updates automatically
- Damage reporting for eligible completed rentals
- Admin dashboard (CRUD for vehicles, bookings, users, damages)
- Configurable hero video on the vehicles page (database-driven URLs)

## Design patterns & SOLID

Implemented in the codebase. **Full explanations, SOLID honesty (what is partial and why), and professor Q&A:** [`demo/STUDY_GUIDE.md`](demo/STUDY_GUIDE.md).

| Pattern / principle | Status | Main classes / notes |
|---------------------|--------|----------------------|
| **Strategy** | Implemented | `PricingPlanStrategy`, `BookingPricing` |
| **Factory** | Implemented | `VehicleFactory`, `VehicleCategoryProfile` |
| **State** | Implemented | `VehicleAvailability` |
| **MVC / layered** | Implemented | Controllers → Services → Repositories → Entities |

## Setup instructions

### 1. Clone the repository

```bash
git clone https://github.com/MahmoudShalaby05/VRS.git
cd VRS/demo
```

### 2. Create the database

In MySQL:

```sql
CREATE DATABASE IF NOT EXISTS vrs_db;
```

Hibernate will create/update tables on first run (`spring.jpa.hibernate.ddl-auto=update`).

### 3. Configure database credentials

Edit `src/main/resources/application.properties`:

```properties
spring.datasource.url=jdbc:mysql://localhost:3306/vrs_db?useSSL=false&allowPublicKeyRetrieval=true&serverTimezone=UTC
spring.datasource.username=YOUR_MYSQL_USER
spring.datasource.password=YOUR_MYSQL_PASSWORD
```

Use your own username and password. **Do not commit real production passwords** to a public repo.

### 4. Build (optional)

From the `demo` directory:

```bash
.\mvnw.cmd clean compile
```


From the `demo` directory:

When the console shows the application started, open:

**http://localhost:8080**
